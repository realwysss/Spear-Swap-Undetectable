# spear swap undetectable

this is the spear swap mod without the server check. the normal spear swap stays off until the server answers with the guard plugin. this one does not wait for it, so it works on every server, with or without the guard.

that also means a server owner can not turn it off with the guard plugin. servers can still ban you for it, so only use it where it is allowed. you are the one who gets banned, not me.

everything else is the same as spear swap: press the key (R by default) with a lunge spear in your hotbar, it swaps to your hand slot, then to the spear, attacks and swaps back. the delays are random between a min and a max you set in mod menu.

## install

minecraft 1.21.11, fabric loader 0.15 or newer, fabric api and cloth config. mod menu is optional but you need it for the settings screen. put the jar from the releases page in your mods folder. do not run it together with the normal spear swap, they have the same mod id.
